B2 · Tính năng

Nhập liệu thông minh, không phải gõ máy móc

Mỗi tính năng giải quyết đúng 1 việc thường gặp khi nhập dữ liệu vào Excel từ 1 danh mục có sẵn.

A1

Lọc thông minh nhiều cột

Gõ vài ký tự, tự động tìm khớp trên nhiều cột cùng lúc, xếp hạng theo mức độ khớp, không cần đúng thứ tự, không cần đúng cột.

B1

Từ viết tắt riêng

Tự định nghĩa viết tắt (ví dụ vt → Viettel), gõ tắt vẫn tìm đúng dữ liệu đầy đủ.

C1

Cột ghi tùy chọn

Chọn đúng cột nào cần ghi vào bảng tính, theo đúng thứ tự mong muốn, không bắt buộc ghi cả dòng dữ liệu nguồn.

A2

Gõ tự do

Gõ không khớp dữ liệu nào vẫn ghi được nguyên văn, có thể bật/tắt riêng cho từng vùng nhập liệu.

B2

Tự động đăng ký

Không cần regsvr32, không cần quyền quản trị máy, mở file .xll là dùng được ngay.

C2

Cấu hình linh hoạt

Mỗi vùng nhập liệu tùy chỉnh riêng: vùng áp dụng, dữ liệu nguồn, cột tìm kiếm, sự kiện kích hoạt.

Cài đặt

Sẵn sàng dùng sau 5 bước

Kiểm tra Excel đang dùng 32-bit hay 64-bit

Mở Excel → File → Account → About Excel, xem dòng đầu tiên.

Tải file .xll đúng phiên bản

Tải tại mục Tải xuống ở cuối trang, chọn đúng file cho bản Excel của bạn.

Mở Add-ins trong Excel

File → Options → Add-ins → mục Manage chọn Excel Add-ins → Go...

Chọn file vừa tải

Bấm Browse..., chọn file .xll → OK.

Dùng ngay

Add-in tự đăng ký, không cần khởi động lại Excel, không cần quyền quản trị.

Bit của Excel không phụ thuộc bit của Windows, máy Windows 64-bit vẫn có thể đang cài Excel bản 32-bit, nên bước 1 là bước quan trọng nhất.
